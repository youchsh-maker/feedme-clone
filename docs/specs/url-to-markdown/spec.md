# URL을 Markdown으로 변환해 LLM으로 넘기기

웹 페이지 URL을 붙여넣으면 본문을 Markdown으로 추출해 보여 주고, 복사, `.md` 다운로드, ChatGPT·Claude로 열기 중 하나로 바로 넘길 수 있게 합니다.

관련 계약:

- [ui-composition](../../decisions/ui-composition.md): 화면의 component, token, 상태 표현, 반응형 규칙을 정합니다.
- [dependency-versions](../../decisions/dependency-versions.md): 새 의존성을 추가할 때 버전 범위를 정하는 기준입니다.
- [prototype.html](prototype.html): 승인된 화면입니다. 배치, 상태(기본, 로딩, 결과, 긴 글 결과, 가져오기 실패), 문구, 본문 렌더링 모양, 좁은 화면 배치를 정합니다. 위쪽 검은 리뷰 바는 제품 화면이 아닙니다. 데이터와 외부 탭 열기는 모의 동작입니다.

## 사용자가 얻는 결과

- URL 하나만 붙여넣으면 광고, 메뉴, 댓글 같은 잡음이 빠진 본문을 Markdown으로 얻습니다.
- 결과 상단에서 페이지 제목과 저자를 보고, 원하는 페이지가 맞는지 바로 판단합니다.
- 클릭 한 번으로 복사하거나 `.md` 파일로 받거나, 고른 프롬프트를 앞에 붙여 ChatGPT나 Claude 새 채팅으로 넘깁니다.
- 라이트/다크 테마를 전환합니다.

## 범위

1. **입력**: URL 입력란 하나와 변환 버튼이 있습니다. 입력란 안의 지우기 버튼을 누르면 입력값과 결과가 모두 초기 상태로 돌아갑니다.
2. **변환**: 본문 추출과 Markdown 변환은 defuddle 라이브러리로 합니다. 페이지는 서버에서 가져옵니다.
3. **결과 확인**: 제목과 저자를 헤더로 보여 주고, 그 아래에 Markdown을 렌더링해 보여 줍니다.
4. **내보내기**
   - 복사하기: Markdown 원문을 클립보드에 복사합니다.
   - 다운로드: Markdown 원문을 `.md` 파일로 저장합니다.
   - ChatGPT로 열기 / Claude로 열기: 선택한 프롬프트를 본문 앞에 붙여 새 탭에서 엽니다.
5. **프롬프트 선택**: 프리셋 "요약해줘", "한국어로 번역해줘", "쉽게 설명해줘"와 "직접 입력"이 나란히 있습니다. 하나만 고를 수 있고, 아무것도 고르지 않을 수도 있습니다. "직접 입력"을 고르면 텍스트 입력란이 나타납니다.
6. **다크모드 토글**: 헤더에서 라이트/다크를 전환합니다.

## 수용 기준

- 유효한 기사 URL(예: `https://stephango.com/file-over-app`)을 넣고 변환하면 제목 "File over app", 저자 "Steph Ango"가 헤더에 보이고 본문이 렌더링된 Markdown으로 표시됩니다.
- 변환 중에는 변환 버튼이 비활성화되고 진행 중임이 보입니다.
- URL 형식이 아닌 값을 넣으면 요청을 보내지 않고 입력란에 오류를 보여 줍니다.
- 페이지를 가져오지 못하거나 본문을 추출하지 못하면 결과 영역에 오류 안내가 보이고, 입력값은 그대로 남아 다시 시도할 수 있습니다.
- 지우기 버튼을 누르면 입력값, 결과, 오류가 모두 사라집니다.
- 복사하기를 누르면 클립보드에 Markdown 원문이 들어가고 복사됐다는 피드백이 보입니다.
- 다운로드를 누르면 `.md` 파일이 저장되고, 내용은 복사하기와 같습니다.
- 프롬프트를 고르지 않고 ChatGPT/Claude로 열면 본문만 전달됩니다. 프롬프트를 고르면 "프롬프트 + 빈 줄 + 본문" 순서로 전달됩니다.
- ChatGPT/Claude로 열기를 누르면 전달할 텍스트가 항상 클립보드에 복사되고 해당 서비스의 새 채팅이 새 탭으로 열립니다.
  - 전달할 텍스트가 주소에 담길 만큼 짧으면 새 채팅 입력란이 그 텍스트로 미리 채워집니다.
  - 길면 텍스트 없이 새 채팅만 열고, "클립보드에 복사했습니다. 붙여넣기(Ctrl+V)하세요" 안내를 보여 줍니다.
- "직접 입력"을 고르면 텍스트 입력란이 나타나고, 거기에 쓴 내용이 프롬프트로 쓰입니다. 페이지를 새로고침하면 그 내용은 남지 않습니다.
- 렌더링된 본문에서 글머리 목록은 기호 대신 바로 위 번호 제목을 따른 소구분 번호로 보입니다("3." 제목 아래 목록은 3.1, 3.2, 3.3). 위에 번호 제목이 없으면 1., 2.로 보입니다. 이 목록은 인용문과 같은 모양(왼쪽 세로선, 흐린 글자색)입니다. 복사·다운로드되는 Markdown 원문은 바뀌지 않습니다.
- 다크모드 토글을 누르면 화면 전체가 즉시 다른 테마로 바뀝니다.
- 좁은 화면에서도 입력, 결과, 내보내기 action이 숨겨지지 않고 위에서 아래 순서로 쌓입니다.

## 확정된 제약과 이유

- **추출은 defuddle로 합니다.** 사용자가 요구한 필수 조건입니다. `defuddle/node`에 DOM 구현(`linkedom` 등)을 붙여 `markdown: true`로 호출하면 `title`, `author`, Markdown `content`를 얻을 수 있음을 defuddle 0.19.6으로 확인했습니다.
- **페이지는 서버에서 가져옵니다.** 브라우저에서 임의의 사이트를 가져오면 CORS에 막히기 때문입니다.
- **긴 본문은 클립보드를 통해 넘깁니다.** ChatGPT·Claude 새 채팅의 `?q=` 미리 채우기는 주소 길이 제한이 있어서 긴 글 전체를 담을 수 없습니다. 본문을 자르면 내용이 빠지므로, 항상 클립보드에 복사하고 짧을 때만 미리 채우기를 함께 쓰기로 사용자와 정했습니다.
- **직접 입력한 프롬프트는 저장하지 않습니다.** 1회용이라는 사용자 요구입니다.

## 가정 (바꿔도 되는 기본값)

- 화면은 한 열 구성이며 배치는 prototype.html을 따릅니다. 위에서부터 헤더(서비스 이름, 다크모드 토글), URL 입력, 프롬프트 선택과 내보내기 action이 담긴 카드, 결과(제목·저자 헤더 + 본문) 카드 순서입니다.
- 미리 채우기는 `https://chatgpt.com/?q=…`, `https://claude.ai/new?q=…` 형식을 씁니다. 인코딩된 주소 전체가 약 8,000자 이하면 "짧다"고 봅니다. 한국어는 인코딩하면 한 글자가 9자로 늘어나므로 이 기준으로는 한국어 본문이 대략 800–900자까지만 미리 채워집니다. 실제 한도는 구현 때 두 서비스에서 확인해 조정합니다.
- 복사·다운로드 내용은 Markdown 원문에 제목과 원본 URL을 맨 위에 붙인 형태이며, 프롬프트는 붙이지 않습니다. 프롬프트는 LLM으로 열 때만 씁니다.
- 다운로드 파일 이름은 페이지 제목을 바탕으로 하고, 제목이 없으면 도메인을 씁니다.
- 저자 정보가 없으면 제목만 보여 줍니다.
- 프리셋을 다시 누르면 선택이 해제됩니다.
- 테마는 처음에 시스템 설정을 따르고, 사용자가 고른 테마는 다음 방문에도 유지됩니다.
- Markdown 렌더링과 테마 전환에는 흔히 쓰는 라이브러리를 씁니다. 버전 범위는 dependency-versions 계약을 따릅니다.

## 범위 밖

- 로그인, 변환 기록 저장, 직접 입력 프롬프트 저장: 1회용 도구로 요청됐습니다.
- ChatGPT·Claude 외 다른 LLM 서비스.
- 서버 쪽 URL 가져오기의 보안 하드닝(내부망 주소 차단, 크기·시간 제한 등): 이 템플릿의 검증 예산상 스펙이 요구하지 않은 하드닝은 범위 밖입니다.
- 로그인이 필요한 페이지나 JavaScript로만 본문을 그리는 페이지의 추출 품질 보장.

## 남은 위험

- ChatGPT·Claude의 `?q=` 미리 채우기는 공식 API가 아니어서 언제든 동작이 바뀔 수 있습니다. 바뀌어도 클립보드 복사와 새 탭 열기는 계속 동작합니다.
- 서버가 사용자가 넣은 아무 URL이나 가져오므로, 공개 배포하면 내부망 접근 같은 악용 여지가 있습니다.
- 일부 사이트는 서버 요청을 차단해 변환에 실패할 수 있습니다. 이때는 오류 안내만 보여 줍니다.
